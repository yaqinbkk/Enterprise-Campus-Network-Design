# Enterprise-Campus-Network-Design
Enterprise 3-tier campus network design built in Cisco Packet Tracer. Features a dual-stack OSPFv2/v3 Area 0 core, Layer 3 routed EtherChannels, HSRP v2 redundancy, and multi-VLAN segmentation. Fully hardened with DHCP Snooping, Dynamic ARP Inspection (DAI), sticky Port Security, BPDU Guard, and restricted SSH access. Includes test verification.
